##  About Me

**물류의 문제를 코드와 데이터로 푸는 사람**이 되려고 합니다.

유통물류학과 컴퓨터공학을 함께 공부하면서, 매장에서 재고가 남아 버려지고 부족해서 못 파는 문제를 데이터로 풀 수 있겠다고 생각했습니다. 그 생각으로 소규모 식당의 재고를 지켜보고 발주까지 제안하는 AI 매장 비서 **Keeping**을 만들었고, Purdue 연구 프로그램에서는 수요예측을 최적화로 연결하는 방법을 배웠습니다. 창업동아리 대표와 창업탐색팀 팀장을 맡으며 기획도 해 본 만큼, 현장과 개발 양쪽을 이해하는 사람으로 재고 · 발주 · 수요예측 서비스를 만들고 싶습니다.

- 🎓 경상국립대학교 유통물류학 & 컴퓨터공학 복수전공
- 🔍 관심 분야: BigData, AI Agent, Computer Engineering, Distribution & Logistics

| 직무 | 왜 이 직무인가 |
|------|---------------|
| **물류 · 리테일테크 백엔드 개발자** (Python / FastAPI) | Keeping 백엔드를 FastAPI · SQLAlchemy · PostgreSQL로 직접 설계하고 구현. 재고 도메인을 이해하는 백엔드 개발자로 성장 중 |
| **물류 시스템 개발자** (WMS / ERP / 물류 SI) | 유통물류학 + 컴퓨터공학 복수전공. 현장의 업무 흐름과 시스템 구조를 모두 아는 개발자를 목표로 함 |

| **수요기획 · 재고관리** (Demand Planning / Inventory Control) | 재고 부족 · 소비기한 임박 감지와 발주 초안 자동 생성 로직을 설계한 경험이 그대로 이어지는 직무 |
